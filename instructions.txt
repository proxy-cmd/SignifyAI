D) CURRENT RUNTIME PIPELINE (REALTIME)
======================================

Primary file
------------
- src/modes/realtime_translator.py

Live loop sequence
------------------
1) Capture frame from camera
2) Detect hand landmarks
3) Build frame vector and sequence buffer
4) Decode by selected mode (default/demo/aid/hybrid path)
5) Apply stability filter
6) Trigger speech if gating allows
7) Draw overlay/panels
8) Emit rolling latency output in terminal

Current notable behaviors
-------------------------
- default mode uses model path tuned for global-first behavior in recent updates.
- single-hand left/right invariance helper exists (_swap_lr_seq).
- shape hint logic exists for c/o/v/r disambiguation (_global_shape_hint).
- no-hand gating/reset logic exists to suppress false chanting.
- speech includes cooldown and stale-label checks.

F) DATA PIPELINE
================

Recording
---------
- File: src/dataset/recording.py
- Records clips into data/landmarks/raw/<session>/
- Saves:
  - clip_XXXX.npz (sequence + timestamps)
  - clips.jsonl
  - session.json

Feature vector format (critical)
--------------------------------
- frame_to_vec output layout:
  1) left hand flattened 63
  2) right hand flattened 63
  3) quality vector 3 (brightness, blur, hand_area)
- total per-frame feature length = 129

Important retraining rule
-------------------------
- If feature layout changes, models must be retrained.

Dataset build
-------------
- File: src/dataset/dataset_builder.py
- Creates train/val/test manifests in data/landmarks/versions/<version>/
- Uses signer-aware split when possible; label fallback otherwise.
- check_dataset() enforces training prerequisites.

Health gating
-------------
- can_train true only if:
  - enough train clips,
  - at least 2 labels in train,
  - non-empty val and test,
  - no missing npz paths.


G) MODEL PIPELINE
=================

Training/evaluation
-------------------
- File: src/model/sequence_model.py
- Candidate algorithms include:
  - logreg, linear_svc_cal, rbf_svc, random_forest, extra_trees, knn, mlp
- Trains candidates and selects best by validation accuracy.
- Saves:
  - data/models/<model_name>.joblib
  - data/models/<model_name>.json

Runtime model loading
---------------------
- load_model_for_runtime(model_name)
- Supports both bundle dict models and legacy/plain sklearn artifacts.

Model registry
--------------
- File: src/model/model_manager.py
- Registry path: data/models/registry.json
- Tracks:
  - active model name
  - promotion history
