SignifyAI - How to Start (Read This First)
==========================================

This project should stay simple and easy to read.
Write code like a student/junior dev would write: clean, clear, and direct.

Rules for all future changes
----------------------------
1) Prefer simple logic over clever logic.
2) Keep functions short and focused.
3) Use normal variable names that are easy to understand.
4) Avoid very long or complex function names.
5) Avoid deep nesting and tricky one-liners.
6) Add small comments only when needed.
7) Keep behavior explicit, not hidden.
8) Do not break existing mode behavior.
9) Run tests after changes.
10) Make commits in small steps with human-style commit messages.

Code style target
-----------------
- A beginner who just finished Python basics should be able to read and edit it.
- If a line looks smart but confusing, rewrite it simpler.
- If a function is doing too much, split it.

Workflow
--------
1) Understand one small task.
2) Implement only that task.
3) Run tests.
4) Commit and push.
5) Ask before starting the next phase.

Reminder
--------
Do not try to fix everything at once.
Improve one phase at a time.
